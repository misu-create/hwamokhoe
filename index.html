가족 소식

📱 홈 화면에 앱 추가하기

홈 화면에 추가하시면 매번 링크를 찾지 않고 스마트폰 앱처럼 버튼 한 번으로 바로 접속하실 수 있습니다.

🤖 삼성 갤럭시 / 안드로이드
1. 화면 우측 상단 또는 하단의 메뉴 버튼(⋮ 또는 ≡)을 누릅니다.
2. 메뉴 목록에서 [현재 페이지 추가] 또는 [홈 화면에 추가]를 선택합니다.
3. [추가]를 누르면 바탕화면에 '화목회' 아이콘이 생성됩니다.
🍎 아이폰 (iPhone Safari)
1. 사파리 화면 하단 중앙의 공유 버튼 (네모 위로 화살표 ↑)을 누릅니다.
2. 스크롤을 살짝 내려 [홈 화면에 추가]를 누릅니다.
3. 우측 상단의 [추가]를 누르면 아이폰 홈 화면에 바로가기가 생성됩니다.
