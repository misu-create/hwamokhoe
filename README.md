# 🌿 화목회 - 우리 가족의 행복한 모임 웹사이트

화목회 50~70대 가족 맞춤형 웹사이트 및 총무 회계 관리 시스템입니다.

---

## 📌 주요 특징 및 설계 기준

1. **50~70대 시니어 중심 가독성 극대화**
   - 본문 기본 폰트 `19~20px`, 중요 회비 금액 `32px` 초대형 볼드 표시
   - 주요 버튼 높이 `58~64px` 이상, 큼직한 터치 영역 확보
   - 복잡한 팝업을 배제하고 모든 화면 상단에 `🏠 처음으로` 버튼 고정 배치
   - 모바일 세로 화면(스마트폰)에 최적화된 앱 스타일 반응형 컨테이너

2. **일반 가족 비로그인 즉시 접근**
   - 카카오톡 단체방('화목회 가족방')에서 링크 클릭 시 로그인/가입 없이 즉시 접속
   - 4대 주요 메뉴: ① 회비 현황, ② 회계 장부, ③ 가족 모임, ④ 공지 사항
   - **가족 개인정보 보호**: 개인별 납부자/미납자 이름은 노출되지 않으며, 가족 전체 요약 통계만 투명하게 제공

3. **총무 전용 10대 관리자 기능 (`admin.html`)**
   - **1. 회원 관리**: 가족 관계(본인, 형제·자매, 사촌, 배우자 등) 설정, 명부 관리
   - **2. 회비 등록 (입금·미납)**: 정상/부분/미납분/선납/일괄납부, 중복 등록 방지, 장부 동시 반영
   - **3. 지출 등록**: 지출 일자, 모임식대/경조사 등 분류, 금액, 영수증 메모, 잔액 실시간 차감
   - **4. 과거 회비 기록 가져오기**:
     - 회원별 x 월별 매트릭스 표 (🟢완료, 🔴미납, 🟡일부, ⚪확인필요, ⚫대상아님)
     - 셀 터치 시 상세 기록 수정 (대상월과 통장 입금일 별도 저장, 미납 보존)
     - 표준 CSV 템플릿 다운로드 및 엑셀 CSV 일괄 업로드 (미리보기, 중복 검사, 유효성 검증)
   - **5. 초기 잔액 설정 및 회계 이관**:
     - A안(과거 전체 거래 합산) vs B안(특정 기준일 시작 잔액 + 기준일 이후 수입/지출 계산)
     - 실제 은행 통장 잔액 vs 계산 잔액 비교 대조 (불일치 시 '확인 필요' 표시)
   - **6. 공지사항 작성·수정**: 가족 홈페이지에 실시간 즉시 반영
   - **7. 가족 모임 및 여행 등록**: 다음 모임 D-Day 배너 및 여행 일정 타임라인 관리
   - **8. 회칙·지원금 관리**: 월 회비 20,000원, 10일 납부, 3개월 미납 유예 설정, 환급 공식, 개정 이력
   - **9. 탈퇴·해산 정산**: 탈퇴 회원 납부액 환급 계산기, 해산 시 잔액 균등 분배 계산
   - **10. 자료 다운로드**: 회원 명부, 전체 납부 기록, 회계 장부를 엑셀(CSV)로 다운로드

4. **테스트 모드 vs 실제 운영 모드 데이터 완전 분리**
   - 테스트 모드(예시 데이터)로 모든 기능을 자유롭게 시험 가능
   - 상단 토글 스위치로 '실제 운영 모드' 전환 시 실제 가족 데이터만 안전하게 관리
   - 테스트 데이터 초기화 시에도 실제 운영 데이터는 절대 삭제되지 않음

5. **카카오톡 공식 JavaScript SDK 연동**
   - 각 화면 하단에 큼직한 노란색 카카오톡 공유 버튼 제공
   - 카카오 API 키 미설정 시에도 '원클릭 안내문 및 링크 복사'로 카카오톡 가족방에 즉시 공유 가능

6. **Firebase Firestore & Cloudflare Pages 완벽 지원**
   - `firestore.rules`: 비로그인 공개 데이터와 총무 전용 비공개 데이터 완벽 격리
   - `scripts/set-admin-claim.js`: 총무 권한 인계 및 Custom Claims (`admin: true`) 도구 제공
   - Cloudflare Pages 무료 정적 웹 호스팅 즉시 배포 가능 (순수 HTML/CSS/JS)

## 🚀 실행 및 배포 방법

### 1. 로컬에서 바로 실행
별도의 빌드 과정 없이 웹 브라우저(크롬, 엣지 등)에서 `index.html`을 더블 클릭하여 바로 열 수 있습니다.

### 2. Cloudflare Pages 무료 배포
1. GitHub 리포지토리에 본 폴더의 파일들을 업로드합니다.
2. [Cloudflare 대시보드](https://dash.cloudflare.com/)에 로그인합니다.
3. **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**을 선택합니다.
4. 방금 올린 리포지토리를 선택하고, Build 설정에서 Build command는 비워두고 Output directory를 `/` (루트)로 설정하여 **Save and Deploy**를 누릅니다.
5. 부여된 무료 도메인 (예: `https://hwamokhoe.pages.dev`)을 가족 카카오톡 '화목회 가족방'에 공유하면 즉시 운영이 시작됩니다.

## 🔐 총무 권한 인계 방법

1. 초기 임시 총무 비밀번호: **`1234`**
2. 관리자 화면 우측 상단 `11. 총무 권한 인계 및 시스템` 메뉴로 이동합니다.
3. 새 총무님의 성함과 새 비밀번호를 입력하고 **[총무 권한 인계 확정]**을 누르면 새 총무님에게 권한이 안전하게 이전되며 감사 로그에 영구 보존됩니다.
4. Firebase Auth 연동 시에는 `node scripts/set-admin-claim.js <새총무_UID>` 명령어로 `admin: true` 권한을 인계할 수 있습니다.
